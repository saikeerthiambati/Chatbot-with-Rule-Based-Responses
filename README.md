# Chatbot with Rule-Based Responses

A simple console-based chatbot built in Python using rule-based logic (if-elif pattern matching). Built as part of the **SAM AI Technologies Internship Program** (Artificial Intelligence track — Task 1).

## Features

- Greets the user and remembers their name
- Tells the current time and date
- Shares random Python / Machine Learning / AI facts
- Solves simple math expressions (e.g. `5 + 3`)
- Gives motivational quotes and compliments
- Calculates approximate age from birth year
- Shows a help menu of all available commands
- Runs in a continuous loop until the user types `bye` or `exit`

## Tech Stack

- Python 3
- Built-in modules: `random`, `datetime`

## How to Run

1. Clone this repository:
   ```
   git clone https://github.com/saikeerthiambati/Chatbot-with-Rule-Based-Responses.git
   ```
2. Navigate into the project folder:
   ```
   cd Chatbot-with-Rule-Based-Responses
   ```
3. Run the chatbot:
   ```
   python "Chat Bot.py"
   ```

## Example Usage

```
Chat Bot: Hi! I'm Bot. Here's what I can do:
  • Greet you (hi, hello)
  • Tell you the time or date
  • Share a Python/AI fact (type 'fact')
  • Solve simple math (like: 5 + 3)
  • Give a motivational quote (type 'quote')
  • Calculate your age (type: I was born in 2005)
  • Give you a compliment (type 'compliment')
Type 'menu' anytime to see this again. Type 'exit' or 'bye' to quit.

You: hi
Chat Bot: Hello! How can I help you today?
You: fact
Chat Bot: Python was named after the comedy show 'Monty Python's Flying Circus', not the snake.
You: 5 + 3
Chat Bot: The answer is 8
You: bye
Chat Bot: Goodbye! Have a great day!
```
